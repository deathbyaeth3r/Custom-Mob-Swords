# Custom Mob Swords

![Custom Mob Swords items](https://user-images.githubusercontent.com/87281729/168843867-6bc534e0-302b-4673-8568-bdee4904d88f.png)

Custom Mob Swords is a Minecraft Forge mod that adds vanilla mob themed swords with unique effects and abilities, including projectiles and potion effects. It also adds gemstone ore and crafting recipes for a selection of swords.

## Requirements

- Minecraft Java Edition 1.15.2
- Minecraft Forge 31.2.55 or a compatible Forge 31.2 build

This branch targets Minecraft 1.15.2. It is not a current Minecraft version port.

## Install

1. Install Minecraft Forge 1.15.2 (Forge 31.2.55).
2. Download the mod jar from the [CurseForge project](https://www.curseforge.com/minecraft/mc-mods/custom-mob-swords).
3. Place the jar in your Minecraft `mods` folder.
4. Start the Forge profile.

## Development

The project uses the included Gradle wrapper. From the repository directory, run:

```sh
./gradlew build
```

The built mod jar is written to `build/libs/`.
